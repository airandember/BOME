# 🔗 ELASTIC BAND: Data Access → Business Logic
**Interface Contract Between Go Database Models and Go Services**

---

## 📍 **Connection Points**

**From**: Go Database Operations (Layer 4 - Data Access)  
**To**: Go Backend Services & Handlers (Layer 3 - Business Logic)  
**Purpose**: Define how database operations are called from business logic

---

## 🎯 **Responsibility Boundaries**

### **Data Access Layer Responsibilities**:
✅ Execute SQL queries safely (prepared statements)  
✅ Map database rows to Go structs  
✅ Handle database errors  
✅ Return structured data or specific errors  
❌ NO business logic (validation, workflows)  
❌ NO HTTP handling  
❌ NO authentication/authorization checks

### **Business Logic Layer Responsibilities**:
✅ Call data access functions with validated input  
✅ Handle business logic and workflows  
✅ Coordinate multiple database operations  
✅ Manage transactions  
❌ NO direct SQL queries  
❌ NO raw database access

## 📊 **Function Contracts**

### **User Operations**

#### `CreateUser(user *User) (*User, error)`
**Called From**: `auth.go:RegisterHandler()`

**Input**:
```go
user := &User{
    Email:         "user@example.com",  // Required, validated
    FirstName:     "John",              // Required
    LastName:      "Doe",               // Required
    EmailVerified: false,               // Default
    PasswordHash:  nil,                 // NULL initially
    Role:          "user",              // Default
    IsActive:      true,                // Default
}
```

**Output - Success**:
```go
createdUser := &User{
    ID:            "123",               // Generated by database
    Email:         "user@example.com",
    FirstName:     "John",
    LastName:      "Doe",
    EmailVerified: false,
    Role:          "user",
    CreatedAt:     time.Now(),          // Set by database
    UpdatedAt:     time.Now(),          // Set by database
}
return createdUser, nil
```

**Output - Errors**:
```go
// Duplicate email (PostgreSQL unique constraint)
return nil, ErrDuplicateEmail

// Invalid input
return nil, ErrInvalidInput

// Database connection failure
return nil, ErrDatabaseConnection
```

**Performance**: <50ms (includes password hashing if applicable)

## 🔒 **Security Contracts**

### **Password Hash Handling**:
```go
// ✅ CORRECT: Include password hash for login verification
user, err := GetUserByEmail(email)
if err != nil {
    return err
}
if !VerifyPassword(user.PasswordHash, password) {
    return ErrInvalidCredentials
}

// ❌ WRONG: Return password hash to business logic for other purposes
// Password hash should ONLY be used for verification, never exposed
```

### **Email Normalization**:
```go
// Business logic MUST normalize before calling data access
email = strings.ToLower(strings.TrimSpace(email))
user, err := GetUserByEmail(email)
```

### **Token Security**:
```go
// Always include userID in token operations for security
session, err := GetSessionByTokenID(tokenID, userID)
err := InvalidateSession(tokenID, userID)
```

## 🔄 **Transaction Handling**

### **When Data Access Needs Transactions**:

**User Registration**:
```go
// Business logic coordinates transaction
tx := db.Begin()
user, err := CreateUser(tx, userData)
if err != nil {
    tx.Rollback()
    return err
}
err = CreateEmailVerificationToken(tx, user.ID, token, expiresAt)
if err != nil {
    tx.Rollback()
    return err
}
tx.Commit()
```

**Login**:
```go
tx := db.Begin()
session, err := CreateSession(tx, sessionData)
err = UpdateLastLogin(tx, userID)
tx.Commit()
```

**Contract**: Data access functions accept optional `*sql.Tx` parameter:
```go
func CreateUser(user *User) (*User, error)
func CreateUserTx(tx *sql.Tx, user *User) (*User, error)
```

## ❌ **Error Handling Contract**

### **Standard Error Types**:
```go
var (
    ErrDuplicateEmail        = errors.New("email already exists")
    ErrUserNotFound          = errors.New("user not found")
    ErrSessionNotFound       = errors.New("session not found")
    ErrInvalidForeignKey     = errors.New("invalid user reference")
    ErrDatabaseConnection    = errors.New("database connection failed")
    ErrQueryTimeout          = errors.New("query timeout")
    ErrConstraintViolation   = errors.New("database constraint violated")
)
```

### **Error Propagation Rules**:
✅ Return specific errors for known cases (duplicate, not found)  
✅ Wrap database errors with context: `fmt.Errorf("failed to create user: %w", err)`  
✅ Use `sql.ErrNoRows` for not found (standard library error)  
❌ Never expose raw SQL errors to upper layers

### **Business Logic Error Handling**:
```go
user, err := database.GetUserByEmail(email)
if err == sql.ErrNoRows {
    return nil, ErrInvalidCredentials  // Don't reveal user doesn't exist
}
if err != nil {
    log.Printf("Database error: %v", err)
    return nil, ErrInternalServer       // Generic error to client
}
```
