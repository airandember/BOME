## 🔍 How to Query Individual User Details

To check subscription details for a specific user in the database:

```sql
SELECT 
    u.id,
    u.email,
    ss.stripe_id as subscription_id,
    ss.status,
    sp.name as product_name,
    spr.unit_amount / 100.0 as price,
    spr.currency,
    spr.recurring_interval as interval,
    ss.current_period_start,
    ss.current_period_end,
    ss.created as subscription_created
FROM users u
JOIN user_stripe_customers_v2 usc ON u.id = usc.user_id
JOIN stripe_customers_v2 sc ON usc.stripe_customer_id = sc.id
JOIN stripe_subscriptions_v2 ss ON ss.customer_id = sc.id
LEFT JOIN stripe_prices_v2 spr ON ss.price_id = spr.id
LEFT JOIN stripe_products_v2 sp ON spr.product_id = sp.id
WHERE u.id = [USER_ID]
  AND ss.status IN ('active', 'trialing')
ORDER BY ss.created DESC;
```
