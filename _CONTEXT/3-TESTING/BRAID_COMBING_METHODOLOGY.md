# 🧪 Braid Combing Methodology

**Simplified Guide for Quick Reference**

---

## THE PROCESS

1. **Pick a strand** (feature to test)
2. **Start at UI** (user interaction)
3. **Trace through layers** (9 layers total)
4. **Document issues** (split-ends)
5. **Verify return** (data comes back)
6. **Mark complete** (strand combed)

---

## THE 9 LAYERS

1. Frontend UI (Component)
2. Frontend Service (API call)
3. Frontend Types (TypeScript)
4. HTTP Request (Network)
5. Backend Handler (Route)
6. Backend Service (Logic)
7. Backend Model (Query)
8. Database (Tables)
9. Return Path (Response)

---

## WHAT TO CHECK

- ✅ **Naming** - Consistent throughout
- ✅ **Paths** - All correct
- ✅ **Types** - Aligned across layers
- ✅ **Data** - Flows correctly
- ✅ **Errors** - Handled properly

---

## WHEN COMPLETE

- No split-ends found OR
- All split-ends documented
- Documentation updated
