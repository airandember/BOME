# 🔧 Split-End Naming Convention

---

## SPLIT-END FILES

### Format
```
SPLIT_END_REPAIR_{BraidName}_{Number}.md
```

### Examples
```
SPLIT_END_REPAIR_AuthBraid_001.md
SPLIT_END_REPAIR_VideoBraid_001.md
SPLIT_END_REPAIR_SubBraid_001.md
```

---

## TRACKER FILES

### Format
```
SPLIT_END_TRACKER_{BraidName}.md
```

### Examples
```
SPLIT_END_TRACKER_AuthBraid.md
SPLIT_END_TRACKER_VideoBraid.md
```

---

## SEVERITY LEVELS

- **CRITICAL** - Blocks functionality
- **HIGH** - Major issue, workaround exists
- **MEDIUM** - Minor issue
- **LOW** - Cosmetic/nice-to-have

---

## STATUS

- **OPEN** - Not yet fixed
- **IN_PROGRESS** - Being worked on
- **RESOLVED** - Fixed
- **CLOSED** - Verified fixed
