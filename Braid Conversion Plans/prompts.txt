```markdown
## Interface Contract: Svelte5 ↔ API Layer

### Contract Definition:
**Authentication State:**
- `isAuthenticated: boolean`

- `token: string | null`
- `loading: boolean`
- `error: string | null`

**API Endpoints:**
- `POST /auth/login` → `auth.login(email, password)`
- `POST /auth/register` → `auth.register(userData)`
- `POST /auth/refresh` → `auth.refreshToken()`

### Error Propagation:
- 401 → `isAuthenticated = false`, redirect to login
- 403 → Show verification required message
- 422 → Display validation errors in form
- 500 → Show generic error message

### State Synchronization:
- JWT token stored in SecureTokenStorage
- User data cached in Svelte store
- Auto-refresh on token expiry
```

### **Example: Business Logic ↔ Data Access Elastic Band**
```markdown
# braids/authentication/layers/business-logic/ELASTIC-BAND-DOWN.md

## Interface Contract: Go Services ↔ Database Operations

### Data Flow Direction:
⚙️ Auth Handlers → 🗄️ Database Models → 📊 PostgreSQL

### Service → Repository Contracts:
**User Operations:**
- `CreateUser(userData) → (*User, error)`
- `GetUserByEmail(email) → (*User, error)`
- `UpdateLastLogin(userID) → error`
- `ValidatePassword(hash, password) → error`

**Session Operations:**
- `CreateSession(userID, tokenID, deviceInfo) → (*Session, error)`
- `GetSessionByToken(tokenID) → (*Session, error)`
- `InvalidateSession(sessionID) → error`

- `sql.ErrNoRows` → User not found (401)

- `connection error` → Service unavailable (503)

- User registration: User creation + Email verification token
```
